解析蓝牙指令

key → 底盘运动：1前进 2后退 3右转 4左转 8停止

key → 蜂鸣器：6播《洒水车》 7停止

slider 1~4 → 机械臂舵机角度（0~180°）

板载外设

4 路舵机：TIM2 CH1~CH4（PA0~PA3，50Hz，0.5~2.5ms）→ 机械臂

蜂鸣器：TIM1 CH1（PA8）

OLED 显示：速度 / 各臂角度

上电初始角度：80° / 130° / 180° / 60°

超声波 HC-SR04：PB10 触发 / PB11 回波（测距函数已写好）

⚠ 代码浏览中发现的疑点（未验证硬件）
  • trigger/main.c：slider 分支末尾把 Angle1~4 强制重置为 38/180/60/60 —— 每次收到滑杆包后机械臂角度会被复位，疑似笔误。
  • trigger/main.c：主函数未调用 Buzzer_Init()，按键 6 播放蜂鸣器时可能无输出。
  • smart car/main.c：已声明自动避障模式与超声波测距，但主循环未接入避障逻辑（front_dis 恒为 0）。
  • smart car/Servo.c：引用 PWM_SetServoCompare3，但该工程 PWM.c 中无此函数定义，需确认该文件是否实际参与编译。
